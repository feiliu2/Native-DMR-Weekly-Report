## 🚀 Quick Start

### 1. Install Dependencies
```powershell
.\scripts\Install-Dependencies.ps1
```

### 2. Generate Report
```powershell
.\scripts\Generate-IFWI-Report-From-Artifactory.ps1
```

You will be prompted for:
- Platform/Stepping (AP1 A0, AP1 B0, or AP2 A0)
- Orange ID (e.g., 2026.26.4.01)
- Simics Version (for Pre-Si only)
- Release info (e.g., "released on WW26.5")
- Artifactory API Token

### 3. Output
Report will be generated in `output/` folder and automatically opened in browser.

## 🔑 Platform Types

| Platform | Silicon Type | Report Type |
|----------|--------------|-------------|
| AP1 A0   | Post-Si      | Simplified (BIOS + UP only) |
| AP1 B0   | Pre-Si       | Full (BIOS + Simics + UP + uBIOS) |
| AP2 A0   | Pre-Si       | Full (BIOS + Simics + UP + uBIOS) |
